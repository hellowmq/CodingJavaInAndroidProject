# CodingJavaInAndroidProject

> Historical Java and Android study workspace, preserved as a learning record.

The repository combines algorithm exercises with earlier experiments in annotation processing, click handling, concurrency, and Android application structure. It is not a reusable Android library or a current application release.

## Modules

- `leetcode`: LeetCode solutions and JUnit-based exercises under `com.wenmq.cn.leetcode`.
- `code`: general Java algorithms, data structures, concurrency, and language experiments.
- `anno`, `task`, `click-anno`, `click-compiler`, `click-api`: annotation-processing and Android instrumentation experiments.
- `app`: Android host used by some of the experiments.

## Status

The project uses Java 8, Android Gradle Plugin 3.6.3, and repositories/tooling from its original development period. It has not been revalidated with current Android Studio, Gradle, JDK, or Android SDK versions. Treat the source as historical examples rather than production-ready implementations.
